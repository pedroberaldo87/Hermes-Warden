Usage: bw restore [options] <object> <id>

Restores an object from the trash or archive.

Arguments:
  object      Valid objects are: item
  id          Object's globally unique `id`.

Options:
  -h, --help  display help for command

  Examples:

    bw restore item 7063feab-4b10-472e-b64c-785e2b870b92
